Interés Simple

Definición

El interés simple es el rendimiento o costo que se calcula únicamente sobre el capital inicial (principal), sin considerar los intereses generados anteriormente.

I = C × i × t Monto Final: M = C + I = C(1 + i × t)
  • I = Interés generado
  • C = Capital inicial (principal)
  • i = Tasa de interés (en decimal)
  • t = Tiempo

¿Por qué funciona así?

El interés simple representa la compensación por el uso del dinero durante un período determinado. Funciona de manera lineal porque:

  • Proporcionalidad directa: A mayor capital, mayor interés. A mayor tiempo, mayor interés.
  • Base constante: Siempre se calcula sobre el mismo capital inicial, lo que hace el cálculo predecible y transparente.
  • Simplicidad: Permite planificar pagos fijos y predecibles.
Capital
+Interés
+Interés
+Interés

El interés se suma de forma constante en cada período

Proceso Paso a Paso

1
Identificar los datos

Determina el capital (C), la tasa de interés (i) y el tiempo (t). Asegúrate de que la tasa y el tiempo estén en las mismas unidades.

2
Convertir la tasa

Si la tasa está en porcentaje, divídela entre 100. Ejemplo: 5% = 0.05

3
Aplicar la fórmula

Multiplica: I = C × i × t

4
Calcular monto final

Suma el interés al capital: M = C + I

Interés Compuesto

Definición

El interés compuesto es aquel que se calcula sobre el capital inicial más los intereses acumulados de períodos anteriores. Es el "interés sobre interés".

M = C(1 + i)ⁿ Interés: I = M - C
  • M = Monto final (capital + intereses)
  • C = Capital inicial
  • i = Tasa de interés por período
  • n = Número de períodos

¿Por qué funciona así?

El interés compuesto refleja el crecimiento exponencial del dinero porque:

  • Reinversión automática: Los intereses generan nuevos intereses.
  • Efecto multiplicador: Cada período tiene una base más grande para calcular.
  • Valor del tiempo: Mientras más tiempo, mayor es el efecto de la capitalización.
Comparación: Simple vs Compuesto

$10,000 al 10% anual por 5 años:

Simple: $15,000
Compuesto: $16,105.10

Proceso Paso a Paso

1
Identificar variables

Capital (C), tasa (i), número de períodos (n) y frecuencia de capitalización.

2
Ajustar tasa y períodos

Si capitaliza mensualmente: i = tasa anual/12, n = años × 12

3
Calcular factor

Calcula (1 + i)ⁿ usando calculadora o potencias.

4
Obtener monto final

Multiplica: M = C × factor

Valor Presente y Valor Futuro

Definición

Valor Futuro (VF): Es el valor que tendrá una cantidad de dinero en una fecha futura.

Valor Presente (VP): Es el valor actual de una cantidad de dinero que se recibirá en el futuro.

VF = VP(1 + i)ⁿ Valor Futuro
VP = VF / (1 + i)ⁿ Valor Presente

¿Por qué es importante?

El concepto del valor del dinero en el tiempo es fundamental porque:

  • Costo de oportunidad: El dinero hoy puede invertirse y generar rendimientos.
  • Inflación: El poder adquisitivo disminuye con el tiempo.
  • Riesgo: Existe incertidumbre sobre recibir el dinero futuro.
  • Preferencia temporal: Las personas prefieren tener el dinero ahora.

Principio clave: Un peso hoy vale más que un peso mañana.

Proceso Paso a Paso

Calcular Valor Futuro
  1. Identifica VP, i, n
  2. Calcula (1 + i)ⁿ
  3. Multiplica VP × factor
Calcular Valor Presente
  1. Identifica VF, i, n
  2. Calcula (1 + i)ⁿ
  3. Divide VF ÷ factor

Medidas de Tendencia Central

Las Tres Medidas Principales

Media (Promedio)
x̄ = Σxᵢ / n

Suma de todos los valores dividida entre la cantidad de datos.

Mediana

Valor central cuando los datos están ordenados. Divide el conjunto en dos partes iguales.

Moda

Valor que más se repite en el conjunto de datos.

¿Por qué usar cada una?

Medida Ventaja Cuándo usar
Media Usa todos los datos Datos simétricos sin valores extremos
Mediana No afectada por extremos Datos con valores atípicos (ej: salarios)
Moda Muestra lo más frecuente Datos categóricos o preferencias

Proceso Paso a Paso

Datos: 5, 8, 12, 8, 15, 8, 20

Media:

1. Suma: 5+8+12+8+15+8+20 = 76

2. Divide: 76 ÷ 7 = 10.86

Mediana:

1. Ordena: 5, 8, 8, 8, 12, 15, 20

2. Valor central (posición 4): 8

Moda:

1. Cuenta frecuencias: 8 aparece 3 veces

2. Moda = 8

Desviación Estándar y Varianza

Medidas de Dispersión

Indican qué tan dispersos o concentrados están los datos alrededor de la media.

σ² = Σ(xᵢ - x̄)² / n Varianza
σ = √σ² Desviación Estándar

Nota: Para muestras, se divide entre (n-1) en lugar de n.

¿Por qué es importante?

  • Mide el riesgo: Mayor desviación = mayor incertidumbre.
  • Calidad: En manufactura, menor variación = mejor calidad.
  • Comparación: Permite comparar la variabilidad de diferentes conjuntos.

1
Calcular la media

x̄ = Σxᵢ / n

2
Restar la media a cada dato

(xᵢ - x̄) para cada valor

3
Elevar al cuadrado

(xᵢ - x̄)² para eliminar negativos

4

Sacar raíz cuadrada

σ = √Varianza

Punto de Equilibrio

Definición

El punto de equilibrio es el nivel de ventas donde los ingresos totales igualan a los costos totales. No hay ganancia ni pérdida.

PE (unidades) = CF / (PV - CV) PE ($) = CF / (1 - CV/PV)
  • PE = Punto de Equilibrio
  • CF = Costos Fijos totales
  • PV = Precio de Venta unitario
  • CV = Costo Variable unitario

¿Por qué es importante?

El punto de equilibrio es crucial porque:

  • Define el mínimo: Cuánto debes vender para no perder dinero.
  • Evalúa viabilidad: Si el PE es muy alto, el negocio puede ser riesgoso.
  • Planificación: Ayuda a establecer metas de ventas realistas.
  • Análisis de sensibilidad: Ver cómo cambios en precios o costos afectan la rentabilidad.

Margen de Contribución: PV - CV = Lo que cada unidad aporta para cubrir costos fijos.

Proceso Paso a Paso

Ejemplo: Una empresa tiene:

  • Costos Fijos: $50,000/mes
  • Precio de Venta: $100/unidad
  • Costo Variable: $60/unidad
1

Margen de Contribución = $100 - $60 = $40

2

PE = $50,000 / $40 = 1,250 unidades

3

PE en $ = 1,250 × $100 = $125,000

Margen de Contribución

Definición

El margen de contribución es la diferencia entre el precio de venta y el costo variable. Representa cuánto "contribuye" cada unidad para cubrir los costos fijos y generar utilidad.

MC = PV - CV Unitario ($)
MC% = (MC/PV) × 100 Porcentual

¿Por qué es importante?

  • Priorización: Productos con mayor MC generan más utilidad.
  • Decisiones de mezcla: Qué productos promover o descontinuar.
  • Negociación: Hasta dónde bajar precios sin perder.
Ejemplo Comparativo
Producto A MC: $30 (30%)
Producto B MC: $50 (50%) Mejor opción

Cálculo del Margen de Contribución

1
Identificar precio y costo variable

PV = precio al cliente, CV = materiales + mano de obra directa + comisiones

2
Calcular MC unitario

MC = PV - CV

3
Calcular MC porcentual

MC% = (MC / PV) × 100

4
MC total (si aplica)

MC Total = MC unitario × unidades vendidas

Porcentajes y Proporciones

Cálculos esenciales para el análisis financiero

Variaciones Porcentuales

Tipos de Cálculos con Porcentajes

Variación = ((Vf - Vi) / Vi) × 100 Cambio porcentual
Vf = Vi × (1 + %/100) Aumento
Vf = Vi × (1 - %/100) Descuento

¿Por qué usar porcentajes?

  • Comparabilidad: Permite comparar cambios en diferentes escalas.
  • Estandarización: Un lenguaje común en finanzas y negocios.
  • Claridad: "Creció 20%" es más claro que "creció $5,000".

Cuidado: Un descuento del 20% seguido de un aumento del 20% NO regresa al valor original. $100 - 20% = $80. $80 + 20% = $96

Ejemplos Prácticos

Calcular variación:

Ventas pasaron de $80,000 a $100,000

Variación = ((100,000 - 80,000) / 80,000) × 100 = 25%

Aplicar aumento:

Precio de $50 aumenta 15%

Nuevo precio = $50 × (1 + 0.15) = $57.50

Aplicar descuento:

Producto de $200 con 30% de descuento

Precio final = $200 × (1 - 0.30) = $140
